=============
Compiled code
=============

ImageD11 uses two sister packages for its compiled code. Their docstrings
are repeated here for convenience. These pages are built from the versions
on PyPI when the documentation was built, which may differ from the version
you have installed.

c2ImageD11
==========

``ImageD11.cImageD11`` imports everything from c2ImageD11. Full
documentation: https://fable-3dxrd.github.io/c2ImageD11/
